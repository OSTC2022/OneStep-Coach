# 러닝 탄수화물 계산기

회원 로그인 없이 `/carb-calculator`에서 엽니다.

체중, 운동 강도, 다이어트 여부, 러닝 시간대, 식사 횟수는 서버에 저장하지 않습니다. 브라우저 `localStorage`와 공유 링크의 쿼리 스트링에만 남습니다.

로그인한 회원이 체중관리에서 키를 바꾸면 그 회원 기록(`members.height_cm`)에 저장됩니다. 이미 회원 정보에 키가 있으면 계산기에 자동으로 채워집니다. 공개 페이지 `/carb-calculator`만 쓸 때는 키도 서버에 저장되지 않습니다.

공유 링크에는 체중(`w`)과 키(`h`)가 포함됩니다. 링크를 받은 사람은 그 값을 볼 수 있습니다.

BMI는 참고 표시이며 탄수화물 계산식에 들어가지 않습니다.
